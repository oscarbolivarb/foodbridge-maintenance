# FoodBridge Legacy App

FoodBridge Legacy App is a small legacy-style Python application used by a nonprofit to coordinate food distribution requests, volunteer assignments, and delivery routing.

## Important
This codebase is intentionally imperfect for course analysis. It includes technical debt, inconsistent structure, weak documentation, and maintainability concerns.

## Main Areas
- request intake and fulfillment
- inventory tracking
- volunteer assignment
- notifications
- simple reporting

## Notes
- Not all files are fully wired together.
- Some configuration values are hardcoded.
- Automated tests are not included.
